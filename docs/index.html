Pacote Django

django_abrasileirado 🎯

Campos nativos de Model e Form para Django (CPFField, CNPJField, CEPField, UFField, MunicipioField) com validação e formatação automática.

Instalação

pip install django-abrasileirado

Em seguida, adicione 'django_abrasileirado' ao seu INSTALLED_APPS no settings.py.

Exemplo em Models

from django.db import models
from django_abrasileirado.models import CPFField, CNPJField, CEPField, UFField

class Cliente(models.Model):
    cpf = CPFField()
    cnpj = CNPJField(blank=True, null=True)
    cep = CEPField()
    uf = UFField()

Desenvolvimento Local

Para executar a suíte Django com PostgreSQL no container local:

cd ~/projetos/PESSOAL/abrasileirado/workspace
./abrasileirado cli django
